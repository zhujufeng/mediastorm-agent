# 独立数据采集助手（本地开发版）

点击左侧「数据采集」即可开始，不需要先打开Git项目。可以描述目标、提供网址或粘贴截图；对话使用已经配置的模型，图片仍需模型支持并单独确认发送。

## 当前可以做什么

- 梳理目标、数据来源、字段、时间/数量范围及重复使用需求。
- 经连接、打开、正文发送三次真实确认，读取指定网页有限可见文字；不继承项目方案批准。
- 用`storm_collection_plan`整理目标、来源、最多12个字段/5条样例、缺失项、范围、最大条数与交付形式/理由，打开真实确认界面。根据场景推荐直接数据、Chrome插件、Python或TypeScript，而非预设插件。
- 点击顶部「采集方案」查看当前记录；重新提出方案会先进入待确认状态，取消或停止不会沿用旧确认。方案保留在原有Pi会话，恢复后仍可查询。
- 新建及恢复采集对话。历史和截图保存在Electron userData中的原有Pi会话，不写业务仓库。

## 当前页数据交付

首次可运行的交付场景是**标准HTML表格的当前页快照**。方案须选直接数据或Chrome插件、明确`capture=current-page-table`和无查询参数的来源地址，并提供至少一条完整预期样例。旧方案没有采集方式时需重新确认。

助手调用`storm_collection_run`后，重新连接/打开/读取网页，每步仍真实确认。只在唯一表格的表头精确对应字段、完整预期样例均匹配时生成结果。最多50条、12列，表格快照最多6000字符；超过方案条数上限、重复表头/记录、合并单元格、页脚、不规则行、敏感字段或截断均不返回部分成功。

顶部「采集方案」显示结果数量和前5条预览，用户可点击CSV/JSON，通过原生保存窗口选择新文件。取消不写入，不覆盖已有文件；保存使用同目录暂存和独占链接，文件系统不支持时明确失败。CSV防公式注入，会将疑似公式值按文本导出；JSON保留原值并携带方案/数据摘要、来源、时间和覆盖限制，建议用JSON保留核验信息。

这只核验字段对应、预期样例及当前DOM快照，不证明全站、分页、虚拟滚动、异步后续数据或时间筛选正确。重新提出方案（即使内容相同）、取消确认或失败重跑都会让旧结果不再可作为当前交付导出。采集规则升级后也需重新运行，原历史不删除。

## Chrome插件交付

需要重复使用时，确认Chrome插件形式后重新运行当前页核验，再点击「导出Chrome插件文件夹」。原生窗口选择保存目录，生成唯一新子文件夹，不覆盖、不自动安装。

文件夹含来源、字段和完整预期样例，可能含业务敏感信息，请勿公开分享。按README在公司策略允许的Chrome中手动加载已解压扩展；打开准确网址并正常登录，点击工具栏插件，再点击读取。只使用activeTab和scripting，不申请Cookie、后台或全站权限；不上传模型、不复制登录状态。关闭MediaStorm后仍可使用；重新导出不会自动更新或撤销已经加载的旧插件，请手动移除旧版再加载新文件夹。

插件复用相同字段、样例及上限检查；成功后预览并由用户点击下载CSV/JSON。重跑/失败/停止清除旧结果；停止只放弃迟到结果，不保证中断已开始的同步DOM读取。预期样例必须仍在当前页，变化后回工作台重新核对，不自动放宽规则。

这是固定标准表格模板，不是任意站点代码生成器。verification.json记录桌面基线、采集规则和生成文件SHA256；弹窗启动时发现配置或文件变化会拒绝读取，需重新导出。这是完整性检查，不是防本机恶意篡改的数字签名，也不表示插件已在使用者真实后台验收。模板已在临时Chrome实际加载并测试权限、读取、重复下载和失败路径；企业策略、真实站点及其他Chrome版本仍需试用。

## 与项目开发的区别

独立入口只加载SDK原生会话、采集提示词、storm_browser_page、storm_collection_plan和storm_collection_run，三种工具互斥，没有read/write/edit/bash、飞书或项目扩展；不会初始化Git/Trellis，也不建立第二套任务数据库。原来的四个项目助手继续使用原工作流和批准规则。需要集成到现有项目时，由用户主动打开项目；项目与采集对话不互相自动恢复历史、复制资料或继承授权。

在采集入口没有Git差异和代码任务面板。浏览器的确认、停止及清理限制保持不变；不是不受限制的网络或操作系统访问。

## 尚未实现

当前是独立需求与有限网页调查入口，不是完整采集交付引擎。字段/样例方案已有结构化记录、摘要及真实确认；只有当前页标准表格data/Chrome插件场景支持实际字段/样例核对，其余场景尚未实现。浏览器来源只绑定本会话成功结果及站点，不证明具体路径或样例正确；截图来源只核对会话有图。确认仅认可需求，不授予执行权限，也不等于交付验收。不能自动翻页采集或执行API；任意采集代码、Python/TS生成与执行仍待开发，Chrome插件仅支持上述固定模板。模型可给建议或草案，但没有实跑证据时不得称交付已通过。

真实后台/SSO、公司数据及扩展策略仍须单独验收。当前回归仅用临时合成网页、图片和回环模型。未安装或发布至同事电脑。

## 检查

`check:all`验证无Git/Trellis、浏览器与方案工具白名单、真实确认取消、上下文/历史隔离及返回项目后的门禁。`check:desktop-ui`验证独立入口、截图、真实合成网页三次确认和读取、新对话/恢复及切回项目；浏览器只由测试预加载器导向临时端点。`check:collection-extension`另将真实生成物加载到临时Chrome，核对activeTab权限、实际弹窗读取和下载真值、停止及失败。CDP触发工具栏动作只用于临时测试，不进入产品。浏览器准备方式见browser-collector-probe.md。
