# MediaStorm Agent 0.6.0 · Mac 预览版

## 新增：自主商品采集

- 直接描述“全部商品，每天采集一遍”，选择已登录页面并授权；助手观察页面的JSON响应，分析字段、唯一ID和总数，不需要你提供接口或选择器。
- 确认字段、真实样例与范围后，从第一页逐页采集，核对数量、重复ID和分页终点。不能证明完整时会停止，不把当前页当作全部。
- 在“采集方案”中导出CSV/JSON，恢复对话后点击“运行已保存方案”即可再次执行，不要求昨天的商品或金额继续存在。
- 停止或登录失效不会把旧结果显示为本次成功；结束后断开连接，不关闭你原有的标签页。Chrome连接失败提供更明确的提示。

## 如何试用

1. 下载DMG，退出旧版MediaStorm Agent，把新版拖入Applications并替换同名应用。账号和已保存对话保留，无需删除应用数据。
2. 打开Chrome并正常登录商品后台，在MediaStorm左侧进入“数据采集”，说明目标和需要的指标。
3. 按界面选择页面并授权，检查助手给出的字段与样例，再运行、导出，与后台核对。
4. 以后恢复这个对话，在“采集方案”点击“运行已保存方案”。

日期政策是**沿用这次页面当前筛选**，不会自动改成今天或昨天。运行前请核对店铺和日期。仍需本人登录与授权，不是无人值守定时任务。

## 验证与边界

已通过合成登录后台的三页采集、次日数据变化、取消/停止、重复页、登录过期、精确数字保留、真实worker/SDK和桌面界面回归，以及独立Mac安装包检查。模型使用本地替身，真实小红书后台、真实模型判断质量与另一台Mac仍由试用验收；本轮未完成新鲜上下文独立审查。

支持已识别的唯一分页组件及GET/POST JSON列表，不保证任意站点、虚拟滚动或请求变体都能运行。每次最多100页、100000条、10MiB输出；无法核对时明确失败。只核对当前范围的分页和数量，不保证所有自定义筛选均被识别，也不是数据库一致性快照。

不读取Cookie或请求头，不执行任意脚本或接口重放；必要业务样例会经授权发送给当前模型。敏感过滤不是匿名化保证。旧Chrome插件仍仅用于当前页标准表格，不是全量插件。

## 安装与更新

适用于Apple Silicon（M系列）Mac、macOS 13.5及以上。Windows与Intel Mac未验证。

仍为ad-hoc签名、未公证预览包，不启用自动安装。可从应用“软件更新”里的“下载与版本记录”下载新版，然后退出应用、手动替换。不要关闭系统安全保护。旧版本下载继续保留。
