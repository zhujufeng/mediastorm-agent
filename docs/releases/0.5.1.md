# MediaStorm Agent 0.5.1 · Mac 预览版

适用于Apple Silicon（M系列）Mac / macOS 13.5及以上。

## Chrome连接修复

修复0.5.0默认Chrome连接入口在连接前就失败、无法到达Chrome授权流程的问题。

原因是把冻结的配置对象直接传给Puppeteer25.10.0，而SDK会补写logger字段，导致TypeError。现在保留冻结的策略常量，在SDK调用时传入新副本。原连接权限、三次用户确认、停止和清理规则不变，没有扩大浏览器权限。

新增真实默认入口回归，不再只依靠替换连接地址的测试：验证SDK配置处理、临时Chrome地址发现、实际连接/读取及自有页面清理。全量检查与独立包检查包含此回归。仍需在你的另一台Mac验证原生Chrome授权和真实后台。

## 更新方法

1. 完全退出旧应用，下载DMG并将新版拖入Applications替换同名应用。
2. 不要删除应用数据目录，原账户与保存的对话会保留。
3. 保持Chrome运行，按Chrome和公司策略允许连接，再重试网页调查。

软件已有左下角“软件更新”入口，但当前未公证预览包只提供“下载与版本记录”，不启用自动安装。完成Developer ID签名、公证和实际升级验证后，正式版才可使用检查更新、下载、重启安装；需要先手动安装一次正式版。不关闭系统或更新签名校验。

本次仍为ad-hoc签名、未公证的预览版，首次打开可能需要按macOS“隐私与安全性”提示处理。只发布DMG和SHA-256，不上传稳定自动更新ZIP。继承0.5.0的功能范围：当前页标准表格与固定插件，不支持自动分页或Python/TS执行。
