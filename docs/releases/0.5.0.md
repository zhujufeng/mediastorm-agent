# MediaStorm Agent 0.5.0 · Mac 预览版

适用于 **Apple Silicon（M系列）Mac / macOS 13.5及以上**。Intel Mac和Windows不适用。

## 本次更新

- 独立「数据采集」入口，无需Git项目；可确认字段、样例、范围与交付形式，恢复历史方案。
- 粘贴或添加PNG/JPEG截图描述需求；视觉模型支持检查及发送前确认，避免静默丢图。
- 受控Chrome网页调查：连接、打开新页、正文发送分别确认；停止和失败清理不会伪装成功。
- 当前页标准HTML表格实际核对、结果预览及CSV/JSON导出；字段、样例、重复项、上限和页面不匹配时拒绝部分成功。
- 导出固定Chrome采集插件文件夹：手动加载后可离开工作台运行，点击读取并下载CSV/JSON。仅activeTab/scripting权限，无Cookie或全站权限；包含业务样例，请勿公开分享。文件及规则变化需重新核验。
- 随包内置官方飞书CLI 1.0.90，业务操作单独确认，不携带开发者账户。
- 三栏工作台、会话搜索、真实方案/差异/检查展示；统一产品工作流上下文，并限制代码审查角色实际可调用的工具。

## 在另一台Mac上试用

1. 下载DMG，将应用拖入Applications后启动。已有旧版先完全退出再替换，不要删除应用数据目录。
2. 这是ad-hoc签名、未公证的预览版；若系统拦截，确认来自本仓库后按系统“隐私与安全性”提示处理，不关闭系统安全保护。
3. 新电脑需自己连接模型。账户、会话、浏览器登录及飞书授权不会随安装包复制过去。
4. 先用非敏感样例验证截图、方案确认、停止、导出和重启恢复。网页调查还需要本机Chrome运行并按Chrome/公司策略允许连接；浏览器不随包提供。
5. 插件请按导出文件夹内README手动加载、运行并对照原页面。新插件不会自动更新或撤销旧插件。

## 已验证与限制

已做本机全量检查、合成页面浏览器回归、实际生成MV3的权限/读取/下载验证、26张桌面回归及独立Mac包检查。模型服务、账户和业务页面使用测试替身，不代表真实后台或另一台Mac已验收。

当前采集仅支持单页标准表格，最多50条、12列及6000字符表格快照；完整预期样例必须仍在当前页，变化时重新核对。不支持自动分页、接口采集、虚拟滚动完整性或Python/TS生成执行；也不证明时间筛选或全站完整。

未完成Developer ID签名、公证及真实自动升级；请手动下载更新。稳定更新ZIP不随此次预览Release发布。DMG的SHA-256见随附校验文件。
