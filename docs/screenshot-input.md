# 截图描述需求（本地开发版）

可以在输入框粘贴一张截图，或点击「添加截图」选择PNG/JPEG。发送前查看预览、移除或自行遮盖敏感内容；没有文字也可以发送。首版单张、4MiB以内、最长边4096像素，不提供截图编辑器或自动脱敏。

## 模型与确认

- 订阅模型按Pi实际模型目录中的图片输入能力判断。中转站默认只有文字；只有服务确实支持图片时，才在高级设置勾选「服务明确支持图片输入」。勾选只是声明，不代表模型已通过真实视觉测试。
- 发送前单独确认接收提供者、模型及中转站地址。截图不会自动遮盖密码、个人或业务秘密，须遵守公司数据政策。
- 取消/停止确认时不向模型发送、不写入会话，草稿保留。确认后图片随原有Pi会话保存在本机userData，后续对话也可能再次发送；不是端到端加密附件库。
- 对话上下文仍有图片时，文字模型不能静默丢图继续。请选择视觉模型或另开文字对话；不自动替换模型。
- 截图不能和斜杠命令一起发送，避免命令处理绕过正常图片输入。

## 保存与切换

实时与历史对话显示图片数量；历史列表不批量回传原始图片，原图保留在本机会话中，暂不提供历史大图查看。拒绝发送保留当前草稿；切换项目/对话清除待发附件，迟到文件读取也不会附加到新项目。未发送图片阻止通过应用内更新重启；主动退出不保存草稿。

## 实现和验证边界

主进程先校验base64、文件签名和尺寸，再用Electron nativeImage解码并重编码成PNG；不接收文件路径、远程图片URL、SVG或其他格式。预览使用主进程返回的规范图片，发送时再次验证，worker也独立验证有界PNG输入。重编码去除原文件元数据，但不会删除图片里的文字秘密。

Pi0.85.1的已安装公开类型定义为`ImageContent {type:'image', data, mimeType}`，通过`session.prompt(text,{images})`提交。本版sdk.md示例仍使用source形式；实现以锁定版本实际类型和回环提供者请求验证为准。

`check:all`验证尺寸/格式限制、模型能力门禁、worker确认取消/停止、实际模型请求中的图片、会话保存恢复及历史有界投影。`check:desktop-ui`验证粘贴/文件选择、原生解码、预览/移除、确认、草稿保留和跨项目迟到读取；只发送生成的合成图片到回环模型，不验证真实模型识图质量。

截图只是表达需求的入口，不自动产生浏览器访问权限，也不能代替在当前网页核对字段、按钮和定位规则。采集调查、生成与实际验证MV3插件仍是后续工作。
