# Mac 桌面助手试用

当前为 0.5.1 桌面预览版，修复Chrome连接入口错误，保留独立数据采集、截图输入、固定Chrome采集插件交付和飞书CLI。首版先支持 **Apple Silicon（M 系列）Mac，macOS 13.5 及以上**；Windows 和 Intel Mac 尚未构建验证。模型入口同时提供账户登录和中转站配置。

## 0.5.0工作台

0.5.0 安装包与`npm run desktop`均提供三栏工作台。升级需退出旧应用后手动替换，原账户和对话保留；另一台Mac需自行连接模型与登录浏览器。

- 左侧搜索当前项目最近 40 个会话；中间按用户回合展开工具过程，公开回答独立显示。停止、工具失败和无最终结果不会冒充检查通过。
- 右上角打开工作详情，分别查看实际任务方案、当前 Git 文件差异和保存的最近检查。方案文档与交付可展开；检查注明命令、时间、退出状态和原始输出，需自行核对跳过项。
- 需求与方案使用中文用途标题，文件名作为次级信息；方案请求默认展开真实需求/方案，验收请求默认展开实际交付与遗留，检查命令显示在决定按钮旁。插件加载数量为次级状态，不代表任务检查成功。
- 只有 Pi 的当前有效方案/验收请求才出现确认按钮，默认焦点为取消。Escape、停止或“我想调整一下”不会批准；修改意见先带入输入框，再由正常对话推进。普通问题继续使用原生弹窗，OAuth 仍在模型设置里。
- Git 查询包括本轮之前已有改动，区分已暂存/未暂存/未跟踪、重命名、删除与二进制。未跟踪内容不读取；最多 100 项、单文件 128 KiB、差异合计 1 MiB，超限明确标记。刷新仅查询 Git，不执行检查。
- 消息、任务文档和检查输出的单段展示最多 60,000 字符，截断会注明；最近 200 条公开消息以外的记录仍在本机会话文件中。内部 custom 与 thinking 不进入桌面消息投影。

新增真实窗口回归：

```sh
env -u TRELLIS_CONTEXT_ID npm run check:all
npm run check:desktop-ui
```

`check:all` 增加消息投影/结构化 Git 断言，不减少原有回归；没有独立 lint/typecheck 配置。`check:desktop-ui` 需可交互 Mac 桌面与已准备的运行时，真实加载 main/preload/renderer/worker/SDK，在临时 Git 项目通过回环 HTTP 模型替身执行确认、失败检查、修复、差异审阅和验收。测试仅保存自己的临时加密凭据，不读取现有账户、不访问外部模型；复制检查会写入一段测试代码到系统剪贴板。测试结束清理临时项目和账户。截图及 JSON 默认保存在 `.local/desktop-ui-evidence`；可用 `STORM_UI_EVIDENCE` 指定证据目录，该变量仅由检查脚本读取。测试脚本作为 Electron 启动入口时，版本栏显示宿主 Electron 版本，不表示产品版本变更。

状态逆序验证另使用确定性屏障：暂停真实 SDK 会话查询后推进任务，再释放查询；缓存一次成功的 catalog，等实际写入使检查失效后才返回，并重放旧 workflow/busy；最后结束测试 worker，在断线后搜索和释放迟到 catalog。断言检查不回退为成功、忙碌不被旧响应解除、确认不复活。屏障仅在测试脚本中，不是生产功能或批准旁路。对应截图 `workspace-15-stale-catalog-rejected.png`、`workspace-16-disconnected.png`。

本地替身检查不代替真实账户、系统中文候选窗口、业务质量或另一台 Mac 的验证；此前账户/安装证据属于下方历史版本，不能直接推定新版已通过这些验证。

## 如何试用

1. 从 [GitHub Release](https://github.com/zhujufeng/mediastorm-agent/releases/tag/v0.5.1) 下载并打开 `MediaStorm-Agent-0.5.1-mac-arm64.dmg`，把 MediaStorm Agent 拖入 Applications。
2. 从启动台打开应用，点击首页“连接模型”或左下角“模型与连接”。以后无需 npm 或终端启动。
3. 有订阅的同事选“订阅账户”，选择服务和模型，点击登录后自动打开浏览器；完成授权后应用自动保存所选模型；用中转站的同事填写服务地址、协议、模型 ID 与密钥，点击“保存并测试连接”验证当前填写的设置。
4. 点击“打开项目”，选择本地 Git 仓库根目录。当前项目完整路径会持续显示；首次使用会准备本项目的 Trellis 任务目录，已有配置不覆盖。
5. 直接说：“帮我优化当前项目，先看看有什么问题。”也可以选择通用开发助手描述明确需求。
6. 在对话中澄清方向，实际方案请求出现后确认或取消（新版源码在右侧工作详情）。确认后自动实现与检查，交付时再由你验收。
7. 点击“文件改动”查看工作目录的 Git 差异；展开对话中的执行结果查看检查输出。文件改动包括此前已有内容，未跟踪文件只列名称。
8. 需要暂停时点击“停止”。重新打开同一项目会恢复该项目最近对话；“新建对话”保留项目任务和已验收经验，左侧对话历史可重新打开旧对话。顶部任务阶段按钮可展开或收起工作详情。Mac 关闭窗口会隐藏应用，Cmd+Q 完全退出。

账户支持来自 Pi 0.85.1 的实际服务定义，例如 ChatGPT、Claude、GitHub Copilot、Kimi 与 xAI；显示在列表不等于账户已具备对应模型权限。登录由本人完成。中转站支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages；地址、模型名称、上下文及输出容量按服务实际值填写。测试连接会发送一个简短模型请求，实际计费按服务规则。

如果授权浏览器未打开，点击“打开授权页面”重试；自动回调无反应时才展开备用输入，粘贴完成授权后的完整回调地址。无需自行编写 URL。也可以取消后重试，OpenAI 另提供设备码方式。

## 当前已经验证的部分

- 实际 Mac 桌面窗口、中文首页、模型设置的键盘可访问标签与密钥保存后不回显。
- Pi 原 SDK/工作流离线回归通过，原方案与验收门槛保持。
- 新桌面回归通过真实 Node 子进程和 Pi SDK，使用本机回环模型替身完成请求、流式输出、持久化对话、项目切换与恢复。
- 同名项目隔离；模型设置与最近项目重启恢复；中转站地址与密钥绑定；确认取消保留待确认状态，确认后才进入实现。
- 最终 DMG 已生成并通过 `check:mac-package`：复制到源码目录之外，验证全部运行时、包内链接、实际 CodeGraph 建索引、SDK 工作流，以及运行后的签名和 DMG 完整性。

**仍是内部预览版。** OpenAI 订阅已由使用者在浏览器完成真实授权，应用自动收到结果并成功请求模型。中文对话、Markdown 表格/代码、复制、历史恢复、文件差异已在桌面操作验证。其他订阅服务、真实中转站完整业务任务及另一台 Mac 安装仍需单独验收。当前只有本机 ad-hoc 签名，尚未完成 Developer ID 签名与 Apple 公证，不能把它称为已完成公司分发。

## 运行环境与数据位置

应用内置 Node 24.14.1、Python 3.12.14、Git 和 CodeGraph 0.9.4，使用 Mac 系统 Bash，不要求同事全局安装 Pi。业务项目自身的依赖、数据库和访问权限仍按项目说明准备。项目未建立 CodeGraph 索引时可以先读文件调查，首次建立仍需要使用者确认。

- 本机设置、加密账户、最近项目与原始对话：`~/Library/Application Support/MediaStorm Agent/`。
- 任务、阶段、检查与项目经验：所选项目 `.trellis/`，不会保存到应用安装目录。
- 凭据用 Mac safeStorage/钥匙串保护后落盘；不放进项目或安装包。不能在不同电脑间直接复制加密账户文件。
- 首版同一时刻使用一个项目；Trellis 终端专属子 Agent 工具暂时禁用。当前源码四个助手共用六个已注册扩展（含飞书 CLI），不提供插件市场、远程执行或后台多任务。

## 开发与打包

```sh
npm ci
npm run desktop:runtime
npm run desktop
npm run check
npm run check:desktop
npm run desktop:package
npm run check:mac-package
```

运行时下载固定版本并核对 SHA-256。`check:desktop` 的 OAuth 回调监听 127.0.0.1:1455，其余模型测试使用临时端口，不访问外部模型；受限执行环境需允许回环监听。`package-mac.mjs` 使用清单复制运行文件、生产依赖和许可证，不包含业务副本、个人登录、历史任务或工作日志。安装镜像包含应用和 Applications 入口。

Trellis 0.6.6 许可保留在 `.trellis/LICENSE`，其脚本与扩展源码随应用分发；依赖的许可保留在各包内。正式公司分发需要结合实际分发内容确认上游许可安排；本预览没有声称已完成许可审查。

软件内更新与维护者发布流程见[Mac 安装与更新发布](releasing.md)。当前试用包尚未完成签名公证，完整升级链路仍待验证。


## 对话中的模型与能力

点击输入框下方的模型名即可搜索和选择已连接服务的模型，方向键移动、回车选择、Esc 关闭。中转站模型在“模型与连接”保存后加入列表；同一地址最多保留 20 个，切换订阅和重启后仍能回来选择。当前只支持一个中转站地址，更换地址需要重新填密钥，并移除旧地址的模型列表。

左侧“Agent 与插件”提供四个内置助手的职责、步骤、交付和提示词；选择作为新任务默认助手，已有任务继续使用原角色。输入框下的插件数量可直接打开实际加载状态。角色与插件开发见 [开发指南](agent-development.md)。
