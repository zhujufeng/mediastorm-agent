# Mac 桌面助手试用

2026-09-10，当前为 0.3.0 桌面预览版，修复首次授权阻塞并重整界面。首版先支持 **Apple Silicon（M 系列）Mac，macOS 13.5 及以上**；Windows 和 Intel Mac 尚未构建验证。模型入口同时提供账户登录和中转站配置。

## 如何试用

1. 打开 `dist/MediaStorm-Agent-0.3.0-mac-arm64.dmg`，把 MediaStorm Agent 拖入 Applications。
2. 从启动台打开应用，点击首页“连接模型”或左下角“模型与连接”。以后无需 npm 或终端启动。
3. 有订阅的同事选“订阅账户”，选择服务和模型，点击登录后自动打开浏览器；完成授权后应用自动保存所选模型；用中转站的同事填写服务地址、协议、模型 ID 与密钥，点击“保存并测试连接”验证当前填写的设置。
4. 点击“打开项目”，选择本地 Git 仓库根目录。当前项目完整路径会持续显示；首次使用会准备本项目的 Trellis 任务目录，已有配置不覆盖。
5. 直接说：“帮我优化当前项目，先看看有什么问题。”也可以选择通用开发助手描述明确需求。
6. 在对话中澄清方向，方案弹窗中确认或取消。确认后自动实现与检查，交付时再由你验收。
7. 点击“文件改动”查看工作目录的 Git 差异；展开对话中的执行结果查看检查输出。文件改动包括此前已有内容，未跟踪文件只列名称。
8. 需要暂停时点击“停止”。重新打开同一项目会恢复该项目最近对话；“新建对话”保留项目任务和已验收经验，左侧对话历史可重新打开旧对话。顶部“任务进度”可展开或收起详情。Mac 关闭窗口会隐藏应用，Cmd+Q 完全退出。

账户支持来自 Pi 0.85.1 的实际服务定义，例如 ChatGPT、Claude、GitHub Copilot、Kimi 与 xAI；显示在列表不等于账户已具备对应模型权限。登录由本人完成。中转站支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages；地址、模型名称、上下文及输出容量按服务实际值填写。测试连接会发送一个简短模型请求，实际计费按服务规则。

如果授权浏览器未打开，点击“打开授权页面”重试；自动回调无反应时才展开备用输入，粘贴完成授权后的完整回调地址。无需自行编写 URL。也可以取消后重试，OpenAI 另提供设备码方式。

## 当前已经验证的部分

- 实际 Mac 桌面窗口、中文首页、模型设置的键盘可访问标签与密钥保存后不回显。
- Pi 原 SDK/工作流离线回归通过，原方案与验收门槛保持。
- 新桌面回归通过真实 Node 子进程和 Pi SDK，使用本机回环模型替身完成请求、流式输出、持久化对话、项目切换与恢复。
- 同名项目隔离；模型设置与最近项目重启恢复；中转站地址与密钥绑定；确认取消保留待确认状态，确认后才进入实现。
- 最终 DMG 已生成并通过 `check:mac-package`：复制到源码目录之外，验证全部运行时、包内链接、实际 CodeGraph 建索引、SDK 工作流，以及运行后的签名和 DMG 完整性。

**仍是内部预览版。** OpenAI 订阅已由使用者在浏览器完成真实授权，应用自动收到结果并成功请求模型。中文对话、Markdown 表格/代码、复制、历史恢复、文件差异已在桌面操作验证。其他订阅服务、真实中转站完整业务任务及另一台 Mac 安装仍需单独验收。当前只有本机 ad-hoc 签名，尚未完成 Developer ID 签名与 Apple 公证，不能把它称为已完成公司分发。

## 运行环境与数据位置

应用内置 Node 24.14.1、Python 3.12.14、Git 和 CodeGraph 0.9.4，使用 Mac 系统 Bash，不要求同事全局安装 Pi。业务项目自身的依赖、数据库和访问权限仍按项目说明准备。项目未建立 CodeGraph 索引时可以先读文件调查，首次建立仍需要使用者确认。

- 本机设置、加密账户、最近项目与原始对话：`~/Library/Application Support/MediaStorm Agent/`。
- 任务、阶段、检查与项目经验：所选项目 `.trellis/`，不会保存到应用安装目录。
- 凭据用 Mac safeStorage/钥匙串保护后落盘；不放进项目或安装包。不能在不同电脑间直接复制加密账户文件。
- 首版同一时刻使用一个项目；Trellis 终端专属子 Agent 工具暂时禁用。两种助手仍共用固定扩展，不提供插件市场、远程执行或后台多任务。

## 开发与打包

```sh
npm ci
npm run desktop:runtime
npm run desktop
npm run check
npm run check:desktop
npm run desktop:package
npm run check:mac-package
```

运行时下载固定版本并核对 SHA-256。`check:desktop` 的 OAuth 回调监听 127.0.0.1:1455，其余模型测试使用临时端口，不访问外部模型；受限执行环境需允许回环监听。`package-mac.mjs` 使用清单复制运行文件、生产依赖和许可证，不包含业务副本、个人登录、历史任务或工作日志。安装镜像包含应用和 Applications 入口。

Trellis 0.6.6 许可保留在 `.trellis/LICENSE`，其脚本与扩展源码随应用分发；依赖的许可保留在各包内。正式公司分发需要结合实际分发内容确认上游许可安排；本预览没有声称已完成许可审查。

软件内更新与维护者发布流程见[Mac 安装与更新发布](releasing.md)。当前试用包尚未完成签名公证，完整升级链路仍待验证。
